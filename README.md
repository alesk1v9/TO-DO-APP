
# To-Do List with Authenticator 

A to-do list app with an authenticator allows users to create, edit, and manage tasks after securely logging in. Users can set a due date for each task and assign priorities (low, medium, high) to help organize tasks by importance. The authentication feature ensures that only authorized users can access and manage their personal task lists.


## Tech Stack

**Client:** React, Bootstrap

**Server:** Node, Express

**Database:** MongoDB
